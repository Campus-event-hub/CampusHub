Workshop details

CampusHub is hosting a Web Design Workshop for students who want to build attractive, usable, and responsive websites.

During this session, participants will learn the essentials of HTML, CSS, page layout, color use, typography, and responsive design principles.

No prior web design experience is required, and students are encouraged to bring a laptop so they can practice hands-on during the session.

What you will learn

  • • Basic HTML structure and semantic layout
  • • CSS styling, spacing, and visual hierarchy
  • • Responsive design for mobile and desktop layouts
  • • Practical tips for building polished, modern web pages

To register or ask questions, email workshop@campushub.edu.
